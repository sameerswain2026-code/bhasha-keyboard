# Privacy notes

Bhasha Keyboard processes typed text locally for core keyboard behavior. Voice typing requires microphone permission and may send audio or transcripts to the configured speech provider when the user activates that feature. Optional AI and search features send only the requested prompt or query to their configured provider.

The application should not log passwords, typed text, clipboard contents, audio, API credentials, or provider responses. A production distribution should publish a complete privacy policy, disclose all providers and retention periods, and provide a support contact before enabling network-backed features.
